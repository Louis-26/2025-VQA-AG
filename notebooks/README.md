# Notebooks Directory

This directory contains Jupyter notebooks for data exploration, analysis, and experimentation.

## Structure

- `exploration/` - Data exploration and visualization notebooks
- `experiments/` - Model training and evaluation experiments
- `analysis/` - Results analysis and visualization

## Usage

Notebooks are ideal for:
- Exploring video datasets and question-answer pairs
- Prototyping models and approaches
- Analyzing submission results
- Creating visualizations for presentations

## Setup

Ensure Jupyter is installed in your environment:
```bash
uv pip install jupyter ipywidgets
jupyter notebook
```
