# Submissions Directory

This directory contains submission files and examples for the TRECVID 2025 VQA Challenge.

## Format

All submissions must be CSV files following the official format:

**AG Task**: `teamname_ag_run1.csv`
**MC Task**: `teamname_mc_run1.csv`

Maximum 3 runs per task per team.

## Note

See `docs/submission.md` for detailed submission guidelines and validation instructions.
